# Расшифровка демонстрационного ролика

45 секунд, 1280×720, пять статичных кадров по 9 секунд. Без звука; текст на кадрах является встроенными титрами. Ролик не содержит записи NVDA, UIA или работы участников.

- **00:00–00:09.** Цель: от невизуальной навигации к доступному имени кнопки. Представлена команда; указано, что это объясняющая демонстрация, а не эксперимент.
- **00:09–00:18.** Реальный снимок тестовой формы в Linux Chromium. Два заложенных барьера: кнопка без имени и поле без связанной подписи.
- **00:18–00:27.** Сравнение кода. Кнопке добавлено aria-label="Поиск". Внешний вид не меняется; свойства и речь в Windows ещё нужно проверить.
- **00:27–00:36.** Архитектура: пользователь, клавиатура, скринридер, UIA, приложение и дерево, синтез речи, брайлевский вывод. UIA — не единственный возможный API доступности.
- **00:36–00:45.** Оставшиеся личные проверки: пять действий, пять элементов, речь/брайль, три типа событий, позитивный/негативный тесты. Ожидания не являются измерениями.

Исходник кадров: `video/slides.html`. Для пересборки нужны PNG каждого `.frame` и FFmpeg; пример — `scripts/render-video.sh`.
