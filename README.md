## Запуск и пересборка

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000` в Edge. Данные формы не отправляются в сеть.

```sh
pip install reportlab Pillow
python scripts/restore-evidence.py
python scripts/build-report.py
```

Для PDF нужен Arial или DejaVu Sans (путь можно задать через REPORT_FONT). В `evidence-source/` находится сжатая base85-упаковка присланных снимков; декодер проверяет контрольные суммы. Это не генерация изображений. ZIP-архивы в репозитории не хранятся.
